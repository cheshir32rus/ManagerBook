## 📖 О проекте

**ManagerBook** — это полноценное обучающее веб-приложение для будущих управляющих ресторанами. Разработано как PWA (Progressive Web App): работает офлайн, сохраняет прогресс, адаптировано под мобильные устройства.

### Для кого
- Администраторы ресторанов, готовящиеся к роли управляющего
- Су-шефы, расширяющие компетенции
- Владельцы ресторанов, обучающие команду

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📖 **15 модулей** | Теория с формулами, таблицами и практическими кейсами |
| 🧩 **75 тестов** | Проверочные вопросы с пояснениями правильных ответов |
| ✅ **Чек-листы** | Интерактивные списки для закрепления практики |

| 📱 **PWA / Офлайн** | Service Worker кэширует приложение для работы без интернета |
| 🎨 **Тёмная тема** | Glassmorphism-дизайн "Ресторанная ночь" |

## 📂 Структура модулей

1. **Ресторан как бизнес-система** — модели, KPI, цепочка ценности
2. **Операционный менеджмент** — открытие/закрытие смены, планирование, контроль качества
3. **Финансовый менеджмент** — P&L, Food Cost, точка безубыточности, меню-инжиниринг
4. **Управление персоналом** — подбор, адаптация, мотивация, дисциплина
5. **Кухня и технологические карты** — техкарты, контроль порционности, mise en place
6. **Закупки, склад и инвентаризация** — поставщики, FIFO/FEFO, ABC/XYZ-анализ
7. **Сервис и гостеприимство** — стандарты, HEARD, NPS, повышение среднего чека
8. **Маркетинг и продажи** — УТП, digital, оффлайн, ROI
9. **Безопасность и законодательство** — ХАССП, СанПиН, ТК РФ, алкогольная лицензия
10. **Кризис-менеджмент** — антикризисный план, негатив в соцсетях, форс-мажоры

## 🚀 Быстрый старт

### Локально

```bash
git clone https://github.com/username/ManagerBook.git
cd ManagerBook
# Откройте index.html в браузере
```

### GitHub Pages

1. Форкните или загрузите репозиторий на GitHub
2. Перейдите в **Settings → Pages**
3. **Source**: Deploy from a branch → `main` → `/ (root)`
4. Сайт будет доступен по адресу:  
   `https://username.github.io/ManagerBook/`

### На телефоне (Android / iOS)

1. Откройте сайт в Chrome (Android) или Safari (iOS)
2. Нажмите **"Добавить на главный экран"**
3. Приложение установится как нативное и будет работать офлайн

## 🛠 Технологии

- **Vanilla HTML5 + CSS3 + JavaScript** — без фреймворков
- **LocalStorage API** — сохранение прогресса
- **Service Worker** — кэширование для офлайн-работы
- **Web App Manifest** — установка на главный экран
